# Hyper-V + Ubuntu Lab

Built a virtual lab on Windows using Hyper-V.

## What I Did
1. Enabled Hyper-V
2. Created External, Internal, Private Virtual Switches
3. Created Generation 2 Ubuntu VM (4GB RAM, 30GB disk)
4. Installed Ubuntu from ISO
5. Verified networking with ip a and ping
6. Created Checkpoint for rollback

## Skills
Hyper-V, Virtualization, Ubuntu Linux, Networking, Virtual Switch, Checkpoint
